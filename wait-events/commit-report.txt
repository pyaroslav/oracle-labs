Read it: 10,000 client-side COMMITs produced 10,017 'log file sync' waits on this session (avg 0.943 ms) --
one synchronous LGWR round-trip per commit. Instance-wide, LGWR did 10,021 'log file parallel write' calls in the same window.
The same 10,000 COMMITs inside one PL/SQL block waited 1 time(s): PL/SQL defers the sync to the end of the call.
The fix for high LFS is almost always BATCHING commits (commit FREQUENCY drives
the event, not row volume), not faster disk.
